# Example — Greenfield proposal

## User request

```text
Use $visualize-design-system to propose and document a semantic color system for a new operations dashboard. There is no existing repository yet.
```

## Expected behavior

- Label all design decisions `proposed`.
- Establish accessibility targets and usage roles before choosing hues.
- Separate primitive scales from semantic roles.
- Provide a token cascade and usage sheet.
- Do not imply that the tokens are implemented or tested in a product runtime.
- Include a handoff-ready JSON token draft only when requested.
