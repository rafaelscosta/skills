# Example — Full visual atlas

## User request

```text
Use $visualize-design-system to audit this component-library repository and create a prioritized plan plus the first production-ready guide for a visual design-system atlas.
```

## Expected behavior

1. Inventory foundations, components, patterns, docs, tests, and render harnesses.
2. Score candidate guides by frequency, ambiguity, risk, accessibility impact, and onboarding value.
3. Propose an atlas taxonomy.
4. Select one representative high-value guide.
5. Produce that guide completely and validate the reusable visual/data contract.
6. Do not render dozens of guides before the first representative guide passes.

## Expected artifacts

```text
atlas-roadmap.md
source-map.json
first-guide/guide-spec.json
first-guide/guide.html
first-guide/exports/guide.png
first-guide/exports/guide.pdf
first-guide/qa-report.md
```
